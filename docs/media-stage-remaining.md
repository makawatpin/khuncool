## 1. Tier A ที่เหลือ 11 แถว

เรียงตามความรุนแรง สาเหตุที่เขียนไว้คือสิ่งที่**ตรวจแล้ว** ไม่ใช่การเดา

### motion-lab — 5 แถว (แถบควบคุมหน้า lab)

| ขนาด | โหมด | ซ่อน |
|---|---|---|
| 375×812 | in-page | 3/7 |
| 375×812 | fullscreen | 1/7 |
| 844×390 | in-page | 3/7 |
| 844×390 | fullscreen | 1/7 |

ที่ซ่อนคือ `↺ รีเซ็ต`, `▶ ปล่อยรถ`, `โจทย์จากการทดลอง 4 ข้อ →` ในแถว `.controls`

**ยังไม่ได้วิเคราะห์ว่าทำไม** — หน้า `lab` มีกราฟจำลองการเคลื่อนที่ซึ่งน่าจะกินความสูง
เริ่มด้วยการวัดว่าแถบควบคุมเหลือที่เท่าไร แล้วดูว่าเข้าเงื่อนไข "หมุนแกน" หรือแค่บีบ

**สาเหตุรู้แล้ว:** ทั้งสองปุ่มนี้เคยเป็น `<span onClick>` และถูกแปลงเป็น `<button>` ใน commit `d4e67ac`

**ข้อควรระวัง:** คอลัมน์ขวายาวได้เรื่อยๆ ตามจำนวนครั้งที่หมุน การ "บีบให้พอดี" อาจไม่พอ
อาจต้องให้รายการเสียงเป็นส่วนที่เลื่อนได้ (ถูกต้องตาม contract เพราะไม่มีปุ่มอยู่ข้างใน)

## 2. หลุม coverage: หน้าผลลัพธ์ที่ไม่เคยตรวจ

`0 hard fails` ครอบเฉพาะ 46 หน้าจอที่ config เดินถึง **หน้าผลลัพธ์ของทุกเกมยังไม่เคยถูกวัดเลย**

รอบก่อนหน้านี้เคยมีหลุมแบบเดียวกัน (family-tree 3 มินิเกม + vocabulary-arcade 3 โหมด)
พอปิดแล้วโผล่มา **33 แถว** ที่ไม่เคยเห็น — เป็นเหตุผลว่าทำไมควรปิดก่อนประกาศจบเฟส

### ตารางต้นทุน (ตรวจจากโค้ดแล้ว)

**กลุ่ม A — คลิกมั่วได้ ตอบผิดก็ไปข้อถัดไป** (ยืนยันจาก `setTimeout` ที่ยิงทุกกรณี)

| เกม | ต้องคลิก | หมายเหตุ |
|---|---|---|
| asean-matching | 11 | `round + 1 >= questions.length` → `setStage("result")` |
| digital-sort | 12 | เหมือนกัน แต่เป็น drag ต้องจำลองการลาก |
| is-are-sorting | 12 | `nextIdx >= queue.length` |
| talk-card | 10 | กด `การ์ดใบถัดไป` จนกลายเป็น `จบเกม 🎉` |
| motion-lab | 4 | quiz 4 ข้อ |

**กลุ่ม B — แพ้ง่ายกว่าชนะ ควรตรวจทั้งสองจอ**

| เกม | ทางลัด | จอที่ได้ |
|---|---|---|
| math-bomb-defusal | มี 3 ชีวิต → ตอบผิด 3 ครั้ง | `lost` (จอ `won` ต้องถูก 10 ข้อ) |
| science-lab-crisis | โครงเดียวกัน | `lost` |

รวมกลุ่ม A + B = **11 หน้าจอ** (46 → 57)

**ต้นทุนเวลา:** การเล่นจนจบทำ 1 ครั้งต่อขนาดจอ (6 ครั้งต่อเกม) เกมละ ~15–60 วินาที
→ full suite จาก ~10 นาที เป็น **~25–30 นาที**

### กลุ่ม C — ต้องเล่นจริง ยังไม่ประเมินละเอียด

- `family-tree` stage 5 — ต้องผ่านมินิเกมครบทั้ง 4 = รวมความยากทุกกลุ่ม

### กลุ่ม D — ไม่มีหน้าผลลัพธ์

`sound-wheel` (หมุนได้เรื่อยๆ) · `law-daily` (อยู่ใน iframe นอกขอบเขต contract)

## 3. phonics-bingo — ไอเดียที่ยังไม่ได้ลอง

เคยตัดออกจากกลุ่ม C เพราะคิดว่าทำอัตโนมัติไม่ได้ (ต้องฟังเสียงแล้วแตะให้ตรง)
**แต่ยังไม่ได้ลองจริง** — เกมมีปุ่ม `👀 ครูดูเฉลย` ที่บอกว่าช่องไหนถูก

แนวทางที่ควรลองก่อนตัดทิ้ง:

1. กด `👀 ครูดูเฉลย` แล้วอ่าน DOM ว่าช่องไหนถูกทำเครื่องหมาย
2. แตะช่องนั้น แล้วกด `🔊 ฟังอีกครั้ง` เพื่อไปเสียงถัดไป
3. ทำซ้ำจนได้บิงโกครบแถว → หน้าผลลัพธ์

ถ้าได้ผล จะได้หน้าผลลัพธ์เพิ่มอีก 1 หน้าจอ และได้วิธีที่อาจใช้กับเกมกลุ่ม C อื่นได้

## 4. ข้อจำกัดที่ยังอยู่ (รู้ตัว ไม่ใช่ลืม)

### วัดจาก headless viewport ตายตัว

`dvh` บนมือถือจริงขยับตามแถบ URL ที่ซ่อน/โผล่ เวทีจริงจึงอาจสูงกว่าที่วัดได้เล็กน้อย
เคสที่คับที่สุดตอนนี้คือ family-tree `plant-tree` (เป้าแตะ 26px) กับ matching (25px)
ทั้งคู่เหลือ margin เหนือเกณฑ์ 24px แค่ 1–2px — **ควรลองบนเครื่องจริงสักรอบ**

### accessibility เหลือ 2 รายการ

| เกม | สิ่งที่เจอ | ทำไมยังไม่แก้ |
|---|---|---|
| digital-sort | การ์ดลาก 1 ใบ (`cursor:grab`) | เป็น drag source ต้องการทางเข้าถึงด้วยคีย์บอร์ด ไม่ใช่แค่เปลี่ยนเป็น button |
| sound-wheel | `<canvas>` วงล้อ (คลิกหมุนได้) | มีปุ่ม `หมุนวงล้อ!` แยกอยู่แล้ว จึงซ้ำซ้อน — อาจแค่ใส่ `aria-hidden` |

### เกมที่ยังไม่ได้ตรวจบางหน้าจอ

นอกจากหน้าผลลัพธ์แล้ว `typing-defense` ยังมีหน้า `levelIntro` ที่เข้าได้เฉพาะโหมด adventure
หลังเล่นจบรอบหนึ่ง — ยังไม่อยู่ใน config

## 5. ลำดับที่แนะนำสำหรับรอบหน้า

1. **Tier A 11 แถว** — sound-wheel (รู้สาเหตุแล้ว) → motion-lab (ต้องวิเคราะห์ก่อน) → family-tree 1 แถว
2. **ปิดหลุม coverage กลุ่ม A + B** (11 หน้าจอ) แล้วรัน full suite ดูว่ามีอะไรโผล่
3. **ลอง phonics-bingo ผ่านปุ่มดูเฉลย** ก่อนตัดทิ้งถาวร
4. ตัดสินใจเรื่อง accessibility 2 รายการที่เหลือ
5. **แล้วค่อยประกาศจบเฟส** — พร้อมระบุให้ชัดว่าตัวเลขครอบหน้าจอไหนบ้าง

> เกณฑ์ก่อนประกาศจบ: hard fails = 0 **และ** Tier A = 0 **และ** หน้าผลลัพธ์อยู่ใน config แล้ว
> ถ้าข้อใดข้อหนึ่งยังไม่ครบ ให้เขียนตัวเลขพร้อมขอบเขตที่มันครอบ อย่าเขียนลอยๆ ว่า "ผ่านหมด"
